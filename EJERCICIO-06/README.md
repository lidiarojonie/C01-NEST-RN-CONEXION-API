# Qué he aprendido 
He aprendido a utilizar `useState` para guardar información que puede cambiar en un componente de React Native y hacer que ese cambio se refleje en la interfaz. También he entendido el recorrido `fetch → JSON → setMensaje → pantalla`.

# Qué he modificado 
He configurado la conexión con el backend y he utilizado useState para guardar la respuesta de GET /mensaje. He añadido los estados 🔴 antes de conectar y 🟢 cuando se recibe correctamente la respuesta.

# Resultado
La aplicación muestra inicialmente el estado 🔴 “Sin conectar” y, al pulsar el botón y recibir la respuesta de NestJS, actualiza la interfaz mostrando 🟢 y el mensaje recibido del backend.
