# Qué he aprendido 
Service array, cómo encaja en el recorrido Full Stack, cómo modificar un ejemplo funcional sin empezar desde cero.

# Qué he modificado 
He añadido una tercera pizza al array del `PizzasService`, incluyendo su emoji y su precio, manteniendo la funcionalidad del endpoint `GET /pizzas`.

# Resultado
El endpoint `GET /pizzas` funciona correctamente y devuelve las pizzas almacenadas en el array del Service, incluida la nueva tercera pizza. El Controller recibe la petición y delega la gestión de los datos al Service.
